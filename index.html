{{ site.description }}

Quick start GitHub

Peekaboot is beta software and may expose security-relevant settings. See Security.

A local run writes traces unmasked to ~/.peekaboot. Set peekaboot.storage.traces.enabled=false to keep them in memory only. See Security, what goes to disk.

Add the dependency

Requires Java {{ site.java_version }} or newer, Spring Boot {{ site.spring_boot_version }} and a servlet web application.

Maven

<dependency>
    <groupId>{{ site.maven_group }}</groupId>
    <artifactId>{{ site.maven_artifact }}</artifactId>
    <version>{{ site.peekaboot_version }}</version>
</dependency>

Gradle

implementation("{{ site.maven_group }}:{{ site.maven_artifact }}:{{ site.peekaboot_version }}")

HTTP API for agents and scripts

Everything the dashboard shows is JSON under /peekaboot/api, which lists its endpoints and links the OpenAPI 3.1 document. See HTTP API, Agents and llms.txt. 

curl -s http://localhost:8080/peekaboot/api | jq
curl -s http://localhost:8080/peekaboot/api/routes | jq
curl -s http://localhost:8080/peekaboot/api/errors | jq

Off on a deployment

Peekaboot is on when you start your app from the IDE, with spring-boot:run or with bootRun, and off for a deployment or a test unless you turn it on. Production use covers what it costs while it is on, what stays on the classpath and how to keep it out of the artifact.
