| File | Written when | Contents | Size |
|---|---|---|---|
| `.lock` | Storage on | None. Held by the instance that writes the directory. | Empty. |
| `insights.snapshot` | Storage on | The insights history, written every `peekaboot.insights.persistence.interval` and at shutdown. It holds the charts' aggregated numbers, keyed by series id. No request data, property values or traces. | About 5 MB at the default levels. |
| `lifecycle.jsonl` | Storage on | One line per start or stop: timestamp, pid, and `version`, `time`, `branch`, `commit.id`, `commit.id.full`, `commit.id.abbrev`, `build.version`, `build.time`. Capped at 1,000 events (about 500 runs), oldest dropped first. | Typically well under 400 KB. |
| `traces.journal.jsonl` | Storage and [trace storage]({{ '/docs/configuration/' | relative_url }}#peekabootstorage) on | Every span, log line and completed request the trace store took since the last fold, one JSON line each. Span attributes, SQL with its bind parameters, log messages and stack traces are unmasked. Request and response headers and parameters are masked as captured. See [Traces across restarts]({{ '/docs/traces/' | relative_url }}#persisted-traces). | Folded once it passes `max-journal-size`. |
| `traces.snapshot.jsonl` | As the journal | The same lines for the traces the store held at the last fold and the untraced log lines it kept. A fold runs at shutdown, once the journal passes `max-journal-size`, and at startup after a run that did not stop cleanly. Masked as the journal is. | What the [trace limits]({{ '/docs/configuration/' | relative_url }}#peekaboottracing) keep. |
| `errors.jsonl` | As the journal | One line per failure in the [error digest]({{ '/docs/api/' | relative_url }}#error-digest): exception class, route, application frame, counts, dates, the last trace id, and the last cause message, masked as the API shows it. Rewritten when it changed, at most once per `flush-interval`, and at shutdown. | A version header and at most 500 entries. |
| `security.properties` | The guard generated a password, and storage is on or `credentials-file` is set | A PBKDF2 hash of the generated password. Never the password itself. | A few lines. |
