| File | Written when | Contents | Size |
|---|---|---|---|
| `.lock` | Storage on | Held by the running instance. | Empty. |
| `insights.snapshot` | Storage on | The insights history, written every `peekaboot.insights.persistence.interval` and at shutdown. Aggregated numbers only: no request data, property values or traces. | About 5 MB at the default levels. |
| `lifecycle.jsonl` | Storage on | One line per start or stop: timestamp, pid, version, build version and time, branch and commit ids. Capped at 1,000 events (about 500 runs), oldest dropped first. | Typically well under 400 KB. |
| `traces.journal.jsonl` | Storage and [trace storage]({{ '/docs/configuration/' | relative_url }}#peekabootstorage) on | Every span, log line and completed request since the last compaction. Span attributes, SQL with its bind parameters, log messages and stack traces are unmasked. Headers and parameters are masked as captured. See [Traces across restarts]({{ '/docs/traces/' | relative_url }}#persisted-traces). | Compacted once it passes `max-journal-size`. |
| `traces.snapshot.jsonl` | As the journal | The traces the store still holds and the untraced log lines it keeps, written at shutdown and when the journal is compacted. Masked as the journal is. | What the [trace limits]({{ '/docs/configuration/' | relative_url }}#peekaboottracing) keep. |
| `errors.jsonl` | As the journal | One line per failure in the [error digest]({{ '/docs/api/' | relative_url }}#error-digest): exception class, route, application frame, counts, dates, last trace id and last cause message, masked as the API shows it. | A version header and at most 500 entries. |
| `security.properties` | The guard generated a password, and storage is on or `credentials-file` is set | A PBKDF2 hash of the generated password. Never the password itself. | A few lines. |
